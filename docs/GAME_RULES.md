# 游戏规则

筹码是娱乐筹码。没有充值、提现或现金奖励。

## 标准无限注德州

`CashGame` 在 `backend/app/engine/`。2 到 9 人。筹码是整数。盲注从按钮左边开始；单挑时按钮是小盲，并先收到第一张牌。发牌顺序是从小盲起顺时针，每人两张，然后烧牌、翻牌三张、烧牌、转牌、烧牌、河牌。

动作是 `fold`、`check`、`call`、`bet`、`raise_to`、`all_in`。`bet` 是本街投入的筹码。`raise_to` 是本街的累计总额。最小加注是上一次加注的增量。短码全下不足一次最小加注时，不重开加注。非法动作抛出 `IllegalActionError`，牌局不变。

街道：`WAITING`、`POSTING_BLINDS`、`PREFLOP`、`FLOP`、`TURN`、`RIVER`、`SHOWDOWN`、`PAYOUT`、`HAND_COMPLETE`。主池和边池按投入分层。未弃牌的玩家在摊牌亮牌。牌力由 `evaluate` 比较，PokerKit 只负责五张牌的大小。

## 可选规则

规则在 `backend/app/rules/`。房间不打开时，牌局就是上面的标准局。房主在手牌进行中修改，下一手才生效。

| 键 | 行为 |
| --- | --- |
| `ante` | `normal`：每位发到牌的玩家各下一份。`bb_ante`：大盲替全桌下一份。前注在底牌发出前进入底池，不算这条街的下注。 |
| `straddle` | `utg`：大盲左边的玩家下 `amount_bb` 倍大盲，翻前从他左边开始。`mississippi`：按钮下 straddle，并在翻前最后行动。`custom`：指定座位下，并最后行动。 |
| `buy_in` | 入座或补码的最小和最大，单位是 `bb` 或 `chips`。 |
| `auto_top_up` | 一手开始时，筹码低于门槛就补到目标。补的是娱乐筹码。 |
| `time_bank` | 截止时间在服务端。面对下注时超时弃牌，否则过牌。 |
| `seven_deuce` | 只有 72 不同花，并且默认必须摊牌赢下。其他发到牌的玩家各付一份赏金。赏金在主池和边池之外。筹码不够就付到零为止。 |
| `run_it_twice` | 翻牌或转牌后，仍在争夺底池的人全部全下，才发起。必须全体同意。每个底池拆成两份，除不尽时第一份多一枚。 |
| `rake` | 派彩时按百分比和上限从底池扣除，单独记录。`no_flop_no_drop` 时翻前结束不抽。 |
| `bomb_pot` | 每位发到牌的玩家下炸弹金额，这一手从翻牌开始。`boards` 为 2 时发两套公共牌，每套单独分池。 |
| `insurance` | 默认关闭。转牌后全员全下、河牌发出前，给出标成 simplified 的报价。保费来自权益。接受只在已有底池里搬筹码。 |

## 短牌和免费赛

短牌是变体 `short_deck`，评估器是 `evaluate_short`。牌从 6 到 A。A-6-7-8-9 是顺子。同花大于葫芦。标准德州的 `evaluate` 不改，葫芦仍然大于同花。

锦标赛是一张冻结桌：盲注级别、筹码输光后离场、最后一名持筹者获胜。没有现金奖励。
